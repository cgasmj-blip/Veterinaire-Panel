# Panel Vétérinaire 🐾

Interface vétérinaire indépendante du panel EMS. Couleur principale : `#D5E9BC`.

## Développement

```bash
npm install
npm run dev
```

## Sécurité

La base Supabase est le projet EMS (`pvahrnrtivzbkipborcd`), schéma privé `veterinary`. Aucun accès direct aux tables n'est accordé au navigateur. L'authentification Discord V.U. et la passerelle EMS doivent être mises en place côté serveur avant toute mise en production.
